# PythonCodes 🚀  
**From Python Basics to AI Bots — A Structured, Practical Learning Repository**

PythonCodes is a carefully designed, step-by-step Python learning repository that starts from absolute fundamentals and progresses all the way to advanced topics, including data analysis, machine learning, and AI agents.

This repository is not just about syntax — it focuses on **thinking in Python**, writing clean code, and building real-world projects.

---

## 🧭 Why This Repository Exists

Most Python resources are either:
- too shallow, or  
- too advanced without foundations, or  
- completely unstructured  

This repo solves that by providing:
- A **clear learning roadmap**
- Industry-aligned folder organization
- Clean `.py` implementations
- Companion `.ipynb` notebooks for exploration
- Mini-projects to apply concepts immediately

## 🧠 How to Use This Repository

### Recommended Learning Flow
1. Follow folders in **numerical order**
2. Read the `README.md` inside each folder first
3. Study `.py` files as the **source of truth**
4. Use `.ipynb` notebooks for exploration and experimentation
5. Build or extend mini-projects after each major section

---

## 📓 `.py` vs `.ipynb` — When to Use What?

| File Type | Purpose |
|---------|--------|
| `.py` | Clean, reusable, production-ready code |
| `.ipynb` | Learning, experimenting, visual explanations |

> Rule: **If code matters, it lives in `.py`.  
If understanding matters, it lives in `.ipynb`.**
