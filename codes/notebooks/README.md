# 📓 Jupyter Notebooks

This folder contains **Jupyter Notebook (`.ipynb`) files** corresponding to the Python concepts and programs in this repository.

These notebooks are designed for **interactive learning, experimentation, and explanation**, while the core implementation logic lives in `.py` files in their respective folders.

---

## 🎯 Purpose of This Folder

The notebooks in this directory serve as:

- 📘 **Learning material** for beginners
- 🧪 **Interactive exploration** of Python concepts
- 📝 **Step-by-step explanations** with live output
- 🌐 **Google Colab–friendly** resources for online execution

They complement the `.py` files but **do not replace them**.

## 🔁 Relationship with `.py` Files

| `.ipynb` Notebooks | `.py` Files      |
| ------------------ | ---------------- |
| Explanation-heavy  | Clean & minimal  |
| Interactive        | Script-based     |
| Markdown + output  | Logic-focused    |
| Beginner-friendly  | Production-ready |

> If you want to *learn or teach*, open a notebook.
> If you want to *build or reuse*, open a `.py` file.
